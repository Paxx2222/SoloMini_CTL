# Root Cause: `ros2` Command Not Found

## Problem
After sourcing workspace setup (`source install/setup.bash`), the `ros2` command is not available:
```bash
$ source install/setup.bash
$ ros2 run solo_usb_controller dual_track_tui_direct
ros2: command not found
```

## Root Cause
**ROS2 base installation is not sourced before the workspace setup.**

The workspace `install/setup.bash` file generated by colcon chains to ROS2 base installation, but only if ROS2 was sourced when the workspace was built. If ROS2 base wasn't sourced during the build, the workspace setup won't include ROS2 base in its chain.

## Solution
Always source ROS2 base installation **before** sourcing the workspace setup:

```bash
# Source ROS2 base first
source /opt/ros/jazzy/setup.bash

# Then source workspace
source ~/ros2_ws/install/setup.bash

# Now ros2 command is available
ros2 run solo_usb_controller dual_track_tui_direct
```

## Fixed Scripts
Updated the following scripts to automatically source ROS2 base:

1. **`scripts/setup_env.sh`** - Now sources ROS2 base before workspace
2. **`scripts/run_tui.sh`** - Now sources ROS2 base before workspace

## Quick Fix for Current Session
If you're in a terminal and need to use `ros2` command immediately:

```bash
source /opt/ros/jazzy/setup.bash
source ~/ros2_ws/install/setup.bash
ros2 run solo_usb_controller dual_track_tui_direct
```

## Permanent Fix
Add to your `~/.bashrc`:
```bash
# ROS2 Jazzy
source /opt/ros/jazzy/setup.bash

# ROS2 Workspace
source ~/ros2_ws/install/setup.bash
```

Or use the updated setup script:
```bash
source ~/ros2_ws/src/SoloMini_CTL/scripts/setup_env.sh
```
